# Shared packages

Thư mục này dành cho các package dùng chung khi NestJS và Next.js được thêm ở các giai đoạn sau:

- `contracts`: kiểu request/response và hằng số dùng chung.
- `database`: entity và migration.
- `config`: cấu hình TypeScript, lint và test.
- `math-renderer`: Markdown và MathJax.

Giai đoạn 1 chưa chuyển nghiệp vụ vào đây để tránh thay đổi hành vi của ứng dụng hiện tại.
